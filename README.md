# Budget Tracker

A web application for tracking income, categorizing expenses, and monitoring spending limits in real time.

## Get Started!

1. Clone or Download the project files,
2. Open SQL Server and run the Script 'DatabaseAndTableCreation', which is in the Script folder,
3. Open the solution in VisualStudio,
4. Set the 'BudgetWebApp' as the start project,
5. Run the Project by clicking on the Play button,
6. Start Budgeting! 

## Tech Stack

- HTML5: Markup
- CSS3 & Bootstrap: Styling
- JavaScript: Interactions
- C#: Backend with database integration
- Font Awesome: Icons
- Google Fonts: Fonts
